# Однослайдовый Доклад

ТЗ из лекций, стр. 118–119: один рисунок основной идеи, одна-две фразы
о результате, базовые обозначения и необходимые термины; доклад до минуты.
Слайд размещается в репозитории, ссылка добавляется в таблицу группы.

## Рассказ На Минуту

Исследую перенос векторной квантизации на диффузионные трансформеры.
Она заменяет группы весов суммами элементов кодбуков.
Перенос VQDM на DiT сжал веса с 32 до 4,15 бита на параметр,
но FID вырос с 6,19 до 15,73. Дальше ищем, где теряется качество.

На графике диагностическая проверка: исходная модель работает на десяти
выбранных шагах, квантованная на остальных. На 256 парных траекториях
используем одинаковые шумы, без сброса латента.
Возврат средних шагов уменьшает конечную ошибку латента на 36,5 процента,
а последних десяти почти ничего не меняет.

Это диагностика, не улучшение FID. Следующая идея: учесть чувствительность
по времени при обучении кодбуков, вместо одинакового отношения ко всем шагам.

## Данные И Сборка

Данные взяты из [сводки статьи](../article_assets/results.json):
`baseline` и `temporal_windows_256`. На графике пять равных окон
из 50 шагов; каждый интервал содержит десять шагов. Диагностика использует
256 пар, FID отдельно считается на 10 000 изображений. Доверительные интервалы
построены парным bootstrap; отрицательная нижняя граница раннего окна
не обрезана.

Исходник самодостаточен, нужны XeLaTeX, Arial, Beamer и PGFPlots:

```powershell
xelatex -interaction=nonstopmode -halt-on-error dit_one_slide.tex
xelatex -interaction=nonstopmode -halt-on-error dit_one_slide.tex
```
