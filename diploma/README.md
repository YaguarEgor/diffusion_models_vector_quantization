# Статья: векторная квантизация диффузионных трансформеров

[Текущий текст статьи](main.pdf) · [LaTeX](main.tex) · [Литература](references.bib)

Рабочая тема: перенос activation-aware векторной квантизации на DiT и анализ
того, какие ошибки по времени и компонентам модели мешают сохранить качество.
Отправная точка — VQDM на DiT-XL/2, ImageNet256. Задача не сводится к сравнению
RVQ с VQDM; RVQ в этот черновик не включён.

## Что Заполнено

- Название, аннотация до 600 знаков и введение под новую тему; язык исходного шаблона сохранён.
- Краткий обзор VQDM, VQ4DiT, PTQ4DiT и HTG с проверенными источниками.
- Формальная постановка: происхождение калибровочной выборки, кодбуки, индексы,
  статистики активаций, ограничение bpp, критерий реконструкции и задача argmin.
- Первые завершённые эксперименты: качество переноса, временные окна,
  семейства слоёв, компоненты adaLN, подстановка предсказаний шума/дисперсии,
  временное взвешивание и отдельные наборы кодбуков с контрольными вариантами.
- Ограничения выводов и дальнейшие проверки. Улучшенный метод и превосходство
  над статьями пока не заявлены.

Проверено по требованиям M1P: [аннотация](https://m1p.org/index.php/Week_2),
[введение и постановка](https://m1p.org/index.php/Week_3),
[первые эксперименты](https://m1p.org/index.php/Week_4).
В экспериментальной части указаны вопросы исследования, данные, конфигурация,
контрольные сравнения, метрики и ограничения выводов. Файлы PDF, TeX и Bib
доступны в этой папке; рисунок не обрезает доверительные интервалы.

Это черновик перечисленных разделов, а не завершённая статья: новый метод
пока не подтверждён, независимые повторения и полный обзор литературы ещё
предстоят. Научные эксперименты здесь не подменяются результатами из статей.

## Файлы Для Репозитория

Для чтения и сборки статьи нужны `main.pdf`, `main.tex`, `references.bib`,
`neurips_2025.sty` и папка `article_assets`:

- `results.tex`: численные значения и строки таблиц, используемые в тексте;
- `temporal_windows.pdf`: рисунок временных вмешательств;
- `results.json`: полные значения выбранных результатов и происхождение данных.

Промежуточные файлы LaTeX не нужны.

## Данные И Пересборка

В `article_assets/results.json` сохранены выбранные результаты с полной
точностью, параметры сравнений, пути исходных сводок и контрольные суммы.
Таблицы и рисунок уже подготовлены; локальные скрипты экспериментов и архивы
кластерных запусков для сборки статьи не требуются.

Из папки `diploma`, при наличии pdfLaTeX и BibTeX:

```powershell
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Для пересборки PDF Python и исходные экспериментальные данные не требуются.
